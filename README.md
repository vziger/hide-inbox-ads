# Hide mail.ru inbox ads

Расширение для Chrome, которое скрывает рекламные блоки в веб-интерфейсе почты **mail.ru**:

- рекламу в правой колонке (карусель баннеров с кнопкой «Убрать рекламу за 1 ₽»);
- рекламный блок в шапке списка писем;
- рекламные строки, встроенные между письмами.

Работает автоматически: скрытие применяется при загрузке страницы и заново — при каждой перерисовке списка (SPA перерисовывает колонки при переходах между письмами и папками).

Состояние вкл/выкл хранится в `chrome.storage.sync` и применяется мгновенно во всех открытых вкладках.

## Установка (режим разработчика)

1. Скачать или склонировать репозиторий.
2. Открыть `chrome://extensions`.
3. Включить **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажать **«Загрузить распакованное расширение»** и выбрать папку с проектом.

После обновления кода нажмите кнопку обновления на карточке расширения и перезагрузите вкладку почты.

## Использование

Иконка на панели открывает попап с переключателем «Скрывать рекламу» и индикатором: сколько рекламных блоков найдено на текущей вкладке. Если написано «Реклама не найдена — её нет или изменилась вёрстка», значит mail.ru поменяли разметку и якоря нужно поправить.

## Структура

```
manifest.json     — манифест расширения (MV3)
content.js        — поиск и скрытие рекламы, MutationObserver
hide.css          — стили режимов скрытия
popup.html/.css/.js — попап с переключателем и индикатором
icons/            — иконки 16/32/48/128
```

## Ограничения

- Работает только на `https://e.mail.ru/*`.
