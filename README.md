# Hide mail.ru inbox ads

Расширение для Chrome, которое скрывает рекламные блоки в веб-интерфейсе почты **e.mail.ru**:

- рекламу в правой колонке (карусель креативов с кнопкой «Убрать рекламу за 1 ₽»);
- рекламный блок в шапке списка писем;
- рекламные строки, встроенные между письмами.

Работает автоматически: скрытие применяется при загрузке страницы и заново — при каждой перерисовке списка (SPA перерисовывает колонки при переходах между письмами и папками).

## Как это работает

Классы вёрстки у mail.ru хешированные и меняются между сборками, поэтому расширение не полагается на них. Реклама опознаётся по устойчивым текстовым якорям, которые рекламная сеть рендерит внутри каждого креатива:

- меню «О рекламодателе / Скрыть рекламу / О рекламе»;
- панель «Объявление скрыто»;
- кнопка «Убрать рекламу за 1 ₽» (правая колонка).

От якоря скрипт поднимается вверх по дереву до корня блока, останавливаясь на границе с интерфейсом почты (иконки/ссылки/кнопки, одинаково свёрстанные соседние письма, элементы во весь экран).

Каждый блок скрывается наиболее подходящим способом:

| Блок | Способ | Почему |
|---|---|---|
| Правая колонка | `opacity: 0` | место сохраняется, чтобы вёрстка письма не прыгала |
| Строка в списке | `display: none` | убирается из потока |
| Реклама в шапке | маска | блок остаётся на месте и держит высоту и скругление верхних углов карточки, прячется только содержимое |

Состояние вкл/выкл хранится в `chrome.storage.sync` и применяется мгновенно во всех открытых вкладках.

## Установка (режим разработчика)

1. Скачать или склонировать репозиторий.
2. Открыть `chrome://extensions`.
3. Включить **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажать **«Загрузить распакованное расширение»** и выбрать папку с проектом.

После обновления кода нажимайте кнопку обновления на карточке расширения и перезагружайте вкладку почты.

## Использование

Иконка на панели открывает попап с переключателем «Скрывать рекламу» и индикатором: сколько рекламных блоков найдено на текущей вкладке. Если написано «Реклама не найдена — её нет или изменилась вёрстка», значит mail.ru поменяли разметку и якоря нужно поправить.

## Структура

```
manifest.json     — манифест расширения (MV3)
content.js        — поиск и скрытие рекламы, MutationObserver
hide.css          — стили режимов скрытия
popup.html/.css/.js — попап с переключателем и индикатором
icons/            — иконки 16/32/48/128
hide ads logo.svg — исходник логотипа
```

## Ограничения

- Работает только на `https://e.mail.ru/*`.
- Опознание завязано на русскоязычные текстовые якоря рекламы. Если mail.ru переименует их или сменит язык интерфейса, скрытие перестанет находить блоки (попап это покажет).
