# Hide mail.ru inbox ads

Расширение для Chrome (Manifest V3), которое скрывает рекламу на нескольких сайтах:

- **Почта Mail.ru** (`https://e.mail.ru/`*) — колонку рекламы справа от списка писем, рекламный блок в шапке списка, рекламные вставки между письмами;
- **Яндекс.Переводчик** (`https://translate.yandex.ru/`*) — рекламную врезку в правой колонке;
- **Яндекс.Погода** (`https://yandex.ru/pogoda/`*) — правый баннер и рекламные карточки;
- **Новая вкладка Chrome** с поиском Яндекса по умолчанию — блок основного рекламного iframe сразу под поисковой строкой; НЕ скрывает ленту с маркет-плейсом, так не имеет доступа к DOM новой вкладки.

На сайтах Mail.ru, Переводчика и Погоды скрытие срабатывает при загрузке и при каждом изменении страницы без полной перезагрузки (SPA, React). Настройки этих трёх площадок хранятся в `chrome.storage.sync` и применяются во всех открытых вкладках соответствующего сайта.

## Установка (режим разработчика)

1. Скачать или склонировать репозиторий.
2. Открыть `chrome://extensions`.
3. Включить **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажать **«Загрузить распакованное расширение»** и выбрать папку с проектом.

После обычного обновления кода нажмите **Обновить** на карточке расширения и перезагрузите вкладку с сайтом.

Если менялись `host_permissions` или правила для новой вкладки (`rules.json`), надёжнее **удалить расширение и загрузить папку заново**, чтобы Chrome запросил новые разрешения и подтянул DNR.

## Использование

Иконка на панели открывает попап с четырьмя галочками:

| Галочка | Где действует |
|--------|----------------|
| Почта Mail.ru | `e.mail.ru` |
| Яндекс.Переводчик | `translate.yandex.ru` |
| Яндекс.Погода | `yandex.ru/pogoda` |
| Новая вкладка (Яндекс) | баннер на NTP (DNR) |

На активной вкладке Mail.ru, Переводчика или Погоды внизу попапа показывается статус: сколько рекламных блоков найдено и включено ли скрытие. Текст вроде «Реклама не найдена» обычно значит, что на странице нет рекламы или сайт сменил вёрстку — якоря в скриптах нужно обновить.

Для новой вкладки статус по счётчику не показывается (URL вкладки недоступен для обычного content-скрипта); работает только галочка.

## Как прячется реклама

Общий приём: атрибут `data-noads-hidden` и стили в `hide.css`.

| Режим | Где | Эффект |
|-------|-----|--------|
| `fade` | правая колонка почты, Переводчик | `opacity: 0`, клики отключены, место сохраняется |
| `collapse` | строки рекламы в списке писем, Погода | элемент убирается из потока (`display: none`) |
| `mask` | реклама в шапке списка почты | блок остаётся по размеру и скруглению, скрывается содержимое |

Почта: поиск по текстовым маркерам меню креатива и классу `.noads-button`, подъём по DOM с защитой от захвата интерфейса почты (`content.js`, `MutationObserver`).

Переводчик: блоки с id, содержащим `R-I-` или `R-A-`, корень — `.side-block` (`yandex.js`).

Погода: классы с префиксами `MainPage_topBlockWithMoney` и `AppMoney_wrap` (`pogoda.js`).

Новая вкладка: блокировка запросов по правилам в `rules.json` (в т.ч. sub_frame с `ntp-sandwich=1` и загрузка `rythm-feed.js`).

## Структура

```
manifest.json       — MV3, content_scripts, declarativeNetRequest
content.js          — почта Mail.ru
yandex.js           — Яндекс.Переводчик
pogoda.js           — Яндекс.Погода
rules.json          — правила DNR для новой вкладки
hide.css            — стили режимов скрытия
popup.html/.css/.js — попап и галочки
icons/              — иконки 16 / 32 / 48 / 128
```

## Ограничения

- Почта: только `https://e.mail.ru/*`, не весь mail.ru.
- Новая вкладка: нельзя менять вёрстку страницы расширением — только резать сетевые запросы; лента или другие блоки Яндекса на NTP могут частично оставаться.
- Между письмами в почте строки иногда позиционируются абсолютно: при скрытии рекламы может остаться визуальная «дырка» между письмами.
- При смене вёрстки на стороне Mail.ru или Яндекса расширение может перестать находить блоки до обновления селекторов или маркеров в коде.
